🧪 MapaLister Vanilla Test Bookmarklet

This bookmarklet clears all MapaLister data and performs a hard reload - perfect for testing with a clean slate.

📌 Installation Instructions

  1. Make sure your bookmarks bar is visible (Cmd+Shift+B / Ctrl+Shift+B)
  2. Drag the button below to your bookmarks bar:

🧪 Vanilla Test MapaLister

  1. Click the bookmark whenever you want to test with a clean slate

⚠️ What This Does

When you click the bookmarklet, it will:

  • Clear localStorage (all saved settings)
  • Clear sessionStorage (temporary data)
  • Delete all IndexedDB databases
  • Unregister all service workers
  • Delete all cache storage
  • Hard reload the page (bypass cache)

Note: This only affects MapaLister data on the current domain. Other sites are not affected.

💡 Alternative: Console Command

You can also paste this into the browser console (F12):

(async()=>{localStorage.clear();sessionStorage.clear();if(window.indexedDB){const dbs=await window.indexedDB.databases();for(const db of dbs){window.indexedDB.deleteDatabase(db.name);}}if('serviceWorker'in navigator){const regs=await navigator.serviceWorker.getRegistrations();for(const reg of regs){await reg.unregister();}}if('caches'in window){const names=await caches.keys();for(const name of names){await caches.delete(name);}}console.log('🎉 Cleared! Reloading...');setTimeout(()=>location.reload(true),100);})();

Tip: Use this before testing new features to ensure no old settings interfere with your tests.
