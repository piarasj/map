About MapaLister

Transform historic data into interactive maps

📚 Historical Data Presentation

MapaLister is a web-based mapping application that presents historical geographic data from the Catholic Parish Registers Geodata Dataset in interactive, searchable maps.

Interchangeable overlays of counties, dioceses, and parishes, as well as markers for diocesan offices, can be readily accessed through an intuitive interface with powerful filtering, search, and navigation tools.

🔒 Privacy First: The upload facility allows bespoke GeoJSON files to show local information, calculating distances from user-created markers. Data in such files is integrated in the display and interaction without the security implications of being published online.

🎯 What Can You Do?

The keys U I O P toggle the display of Diocesan offices, Dioceses, Counties and Parishes respectively. Keys invoke up to three states cyclically:

  • Hidden - No display
  • Outlined - Display only, no information
  • Coloured - Mouseover shows information following the cursor position

By using the Settings menu, the opacity and outlines of the overlays can be configured.

📊 Data Presented

The National Library of Ireland's collection of Catholic parish register microfilms which contain records of baptisms and marriages from the majority of Catholic parishes in Ireland and Northern Ireland up to 1880.

Data Modifications

  • The Catholic Parish Registers Geodata included workhouses which are omitted in this presentation.

Known Anomalies

  • Modern parish changes are not shown
  • Boundaries and details are not available for urban parishes

🔧 Technical Details ▼

Architecture

MapaLister is a client-side Progressive Web App built with vanilla JavaScript - no frameworks, no build system, no backend server. The application uses a modular IIFE pattern with explicit dependency checking and event-driven communication.

Core Technologies

Mapbox GL JS v2.15.0 Lucide Icons LocalStorage API Service Worker File API

Key Implementation Details

Dependency Management

  • Each manager checks dependencies before initialisation
  • Custom event system (mapalister:coreReady, mapalister:configReady) handles async loading
  • Strict script loading order enforced in HTML (18 scripts in specific dependency sequence)

Event Bus Architecture

  • Custom event bus pattern for inter-component communication
  • Key events: map:loaded, sidebar:stateChanged, settings:changed
  • Decouples managers while maintaining coordination

Dynamic Configuration

  • DataConfig adapts to uploaded data structure automatically
  • Detects grouping properties (e.g., "dataset", "diocese", "region")
  • Generates colour mappings for dataset visualisation
  • No hardcoded schemas - works with any GeoJSON structure

Geometry Support

  • Handles Polygon, MultiPolygon, and Point features
  • City parishes (73 urban point features) rendered as circle markers
  • Layer existence checking prevents query errors
  • Unified pop-up system works for both geometry types

Search System

  • Parish name variants: 1,142 parishes → 3,143 variant entries
  • Reverse lookup map for O(1) variant resolution
  • Normalisation fallback strips city suffixes for resilience
  • Debounced search (300ms) for smooth filtering

Performance Optimisations

  • iOS Safari-specific canvas rendering fixes
  • Touch scrolling optimisation for mobile
  • Event handler cleanup prevents memory leaks
  • Contextual zoom levels (don't fill screen unnecessarily)

Security & Privacy

  • Zero backend communication (except Mapbox tiles)
  • All data processing client-side
  • Public Mapbox token (domain-scoped)
  • No sensitive data leaves the browser

Browser Compatibility

Modern browsers are required (Chrome, Firefox, Safari, Edge) with optimisations for iOS Safari touch handling and viewport management.
