URL Navigation Test for MapaLister

Click these links to test URL-based navigation to parishes:

Test 1: Parish Navigation
http://localhost/map/#parish=Kilkenny
Test 2: Different Parish
http://localhost/map/#parish=Dublin
Test 3: County Navigation
http://localhost/map/#county=Cork
Test 4: Coordinate Navigation
http://localhost/map/#lat=53.3498&lng=-6.2603&zoom=12 (Dublin)

How to Test:

  1. Click each link above to open the map in a new tab
  2. Verify that the map navigates to the correct location
  3. For parish/county links, check that the sidebar shows filtered results
  4. For coordinate links, check that the map centers on the specified location

Expected Behavior:

  • The URL should trigger a search for the parish/county name
  • The sidebar should filter to show matching results
  • The first matching result should be selected and shown on the map
  • A popup should appear for the selected location

Note: Make sure your local server is running on localhost and the map application is accessible.
